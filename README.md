# Portfolio Website

## Description

This is a personal portfolio website showcasing my projects, skills, and professional experience. Built with modern web technologies, the site offers an interactive and visually appealing representation of my work.

## Live Demo

🌐 [View Live Portfolio](https://sathwickreddyy.github.io/sathwick-portfolio/)

## Technologies Used

- **Frontend Framework**: React
- **Bundling**: Vite
- **Styling**: Tailwind CSS
- **State Management**: Redux Toolkit
- **Animation Libraries**: 
  - GSAP
  - Framer Motion
  - React Three Fiber
- **3D Rendering**: Three.js
- **Email Integration**: EmailJS

## Features

- Responsive design
- Interactive 3D elements
- Smooth animations
- Contact form with EmailJS integration
- Redux state management
- TypeScript support

## Performance Optimization

- Lazy loading implemented
- Code splitting with Vite
- Optimized 3D renderings
